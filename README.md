# پرتو | پخش ویدیو روی تلویزیون

اپ اندرویدی Kotlin و Jetpack Compose برای فرستادن ویدیوهای گوشی یا لینک‌های ویدیویی به تلویزیون در شبکهٔ محلی.

## امکانات

- اتصال به Google Cast با انتخاب‌گر رسمی دستگاه‌های Cast
- کشف تلویزیون‌های سازگار با DLNA/UPnP در شبکهٔ Wi-Fi و ارسال فرمان پخش
- فهرست، جست‌وجو و انتخاب ویدیوهای گوشی
- اشتراک‌گذاری فایل محلی از طریق سرور HTTP محدود به همان فایل و پشتیبانی از درخواست‌های Range
- مرورگر درون‌برنامه‌ای برای شناسایی منبع‌های قابل‌دسترسی HTML5 ویدیو و ارسال آن‌ها به تلویزیون
- تم تیرهٔ شیشه‌ای، رابط راست‌به‌چپ فارسی و نوار پخش پس‌زمینه برای پخش محلی

صفحه‌های وب فقط وقتی قابل ارسال‌اند که ویدیوی مستقیم و قابل‌دسترسی در HTML داشته باشند. DRM، سرویس‌هایی که جریان رسانه را پنهان یا محافظت می‌کنند، و محدودیت‌های کوکی/احراز هویت ممکن است مانع پخش روی تلویزیون شوند. سازگاری کدک‌ها و فرمت‌ها به خود تلویزیون بستگی دارد.

## پیش‌نیازها

- Android Studio یا ابزار سازگار با پروژه‌های Android
- Android SDK Platform 36 و Build Tools
- JDK 17 یا 21

در Android Studio پروژه را باز کنید و پس از Gradle Sync پیکربندی `app` را روی گوشی یا شبیه‌ساز اجرا کنید. برای ساخت APK اشکال‌زدایی:

```bash
./gradlew assembleDebug
```

خروجی در `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد. برای نصب روی دستگاه متصل:

```bash
./gradlew installDebug
```

برای پخش تلویزیونی، گوشی و تلویزیون باید روی یک شبکهٔ محلی باشند. برای نمایش کتابخانهٔ رسانه، اجازهٔ دسترسی به ویدیوها را بدهید. اگر در Google Cast تلویزیون پیدا نشد، اتصال DLNA را از زبانهٔ تلویزیون‌ها جست‌وجو کنید.

تست‌های JVM:

```bash
./gradlew testDebugUnitTest
```
