# پرتو | پخش ویدیو روی تلویزیون با Wi-Fi

اپ اندرویدی Kotlin و Jetpack Compose برای فرستادن ویدیوهای گوشی یا لینک مستقیم ویدیو به تلویزیون روی شبکهٔ Wi-Fi مشترک. تلویزیون‌های سازگار با DLNA/UPnP به‌صورت خودکار پیدا می‌شوند و برنامه فرمان پخش را مستقیماً برایشان می‌فرستد؛ برای تلویزیون‌های ناسازگار، صفحهٔ پخش HTTP محلی همچنان مسیر جایگزین است.

## روش استفاده

1. گوشی و تلویزیون را به یک شبکهٔ Wi-Fi وصل کنید.
2. در برنامه به کتابخانه بروید و دسترسی ویدیوها را بدهید.
3. در زبانهٔ «اتصال تلویزیون»، تلویزیون را جست‌وجو و انتخاب کنید.
4. ویدیویی را از کتابخانه انتخاب کنید یا لینک مستقیم MP4، MKV، WebM، MOV، AVI، M3U8 یا MPD را در بخش لینک وارد کنید؛ پخش روی تلویزیون آغاز می‌شود.
5. اگر تلویزیون DLNA/UPnP ندارد یا فایل را پشتیبانی نمی‌کند، آدرس جایگزین نمایش‌داده‌شده را در مرورگر تلویزیون باز کنید.

پخش مستقیم به تلویزیون به پشتیبانی تلویزیون از DLNA/UPnP و فرمت فایل وابسته است. برای لینک‌های مستقیم، تلویزیون باید به URL واردشده دسترسی داشته باشد. سازگاری MKV یا سایر کدک‌ها به مدل تلویزیون بستگی دارد.

**توجه:** ارتباط HTTP رمزنگاری نمی‌شود. سرور فقط هنگام پخش فعال است، اما هر دستگاهی که به شبکهٔ محلی دسترسی داشته باشد و آدرس تصادفی نمایش‌داده‌شده را بداند می‌تواند ویدیو را دریافت کند. از شبکهٔ مطمئن استفاده کنید و آدرس را عمومی به اشتراک نگذارید.

## پیش‌نیازها

- Android Studio یا ابزار سازگار با پروژه‌های Android
- Android SDK Platform 36 و Build Tools
- JDK 17 یا 21

نسخهٔ جاری: **2.2.1**. فایل نصب و تغییرات هر نسخه از بخش [Releases مخزن](https://github.com/hadi4293/Htii/releases) در دسترس است.

در Android Studio پروژه را باز کنید و پس از Gradle Sync پیکربندی `app` را روی گوشی یا شبیه‌ساز اجرا کنید. برای ساخت APK اشکال‌زدایی:

```bash
./gradlew assembleDebug
```

خروجی در `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد. برای نصب روی دستگاه متصل:

```bash
./gradlew installDebug
```

برای نمایش کتابخانهٔ رسانه، اجازهٔ دسترسی به ویدیوها را بدهید. آدرس گیرنده پس از انتخاب ویدیو در برنامه ساخته می‌شود.

تست‌های JVM:

```bash
./gradlew testDebugUnitTest
```
